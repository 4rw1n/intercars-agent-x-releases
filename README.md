# Intercars Agent X — Stable Update Channel

Ovaj javni repozitorij služi isključivo za distribuciju provjerenih Intercars Agent X ažuriranja.

- Source code ostaje u privatnom repozitoriju.
- Ovdje se ne čuvaju konfiguracija, baze, WooCommerce/OLX tajne, tokeni, browser profili ili korisnički podaci.
- `update-manifest.json` je stable kanal koji desktop aplikacija provjerava preko HTTPS-a.
- Release paketi trebaju biti kompajlirani Windows `windows-onefolder` paketi sa SHA-256 provjerom.

Korisnički podaci ostaju izvan programskog foldera u `Documents\IntercarsAgentData` i updater ih ne zamjenjuje.
